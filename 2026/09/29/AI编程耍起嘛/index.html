野人时代

如果是在2024年前，那你可能会认为是写汇编写C就是古法编程。
但在today，这个说法已经扩展到用编辑器敲任何代码都叫古法编程了。在这个连牢理@Mashiro_Neri都能靠大肥鱼写出复杂逻辑的代码的今天（能不能用你别管），坚持手敲代码，看起来就像是原始人。
本人在25年是一个合格的古人，古到哪种程度呢？古到什么都是自己写。红石镇的bot是我手写的，说实话我真佩服以前的我，在牢理@Mashiro_Neri套docker，使用nas和不稳定的环境，无本地bot框架和测试环境的情况下半天内完成了对插件基础功能的开发。
在学校中在同学豆包play完成实验报告的情况下我依旧手写，发挥匠人精神，可惜这种日子将在下半年结束……

在25年之前，我一直想着手写代码来训练自己的基本能力，毕竟AI是黑奴，指挥黑奴你得学会怎么指挥，光拿鞭子抽只会事倍功半。
直到寒假过后，嵌入式课程，他来了……
我们的嵌入式是我们前院长（现在是副院长，大佬实在太忙碌了所以退去了院长职位），他告诉我们：

“AI编程是要搞的，不搞不行！”

我就开始了AI玩耍了，但是玩耍AI也没有正儿八经的使用AI编程工具，还在属于比较抵触的阶段。
AI编程属于比较不可控的过程，因为代码不是你自己写的，安全性跟可靠性一直是未知数，并且依赖AI你会失去手写代码的神力，所以在此阶段我一直是比较克制的使用AI（只使用网页对话）。
我深深的体会到了网页版的局限性：
1.AI不能直接操作

  • 这一点很明显，所有的操作你得自己来

2.免费版的网页模型是傻子

  • 即使是深度思考，所体会出来的智慧简直是天差地别

3.网页对话有 token 上限：

  • 很难一次性读懂完整项目；只能复制粘贴片段，无法自动读取整个项目目录；
  • 多文件项目需要手动反复粘贴各个文件代码，容易丢失上下文，改代码容易出现前后不一致

但压死最后一根稻草的骆驼（这句话没绷住）是因为25年4月老师发的一条消息：

“嵌入式已进入寒冬。”

封面是老英雄，设敬！
我也绝得是时候真正进入AI编程了。

对于AI，其实我一直都有学习，什么多模态，Agent，skill等词汇我这个古人也是略知一二，但是国外的月亮我是一点都没见到过
众所周知，AI编程有两种：
一种是AI智能补全

AI智能补全对我来说没啥吸引力就索性不玩了，直接开始了Agent玩耍，可没想进入了魔窟……

从前的我已经死了。

Agent是什么？

用deepseek的话来说是这样：

Agent（智能体 / 代理），简单说就是：能感知环境、自己做决策、采取行动，以完成某个目标的系统或程序。它不一定是有实体的机器人，也可以是一段软件。
今天大家说“Agent”，多数时候特指 AI Agent / LLM Agent，也就是以大语言模型为“大脑”的智能体。
可以把它理解成：
Agent = 大模型 + 记忆 + 工具 + 规划 + 执行循环
AI Agent 的核心组成
模型/大脑：负责理解任务、推理、决策，比如 GPT、Claude 等。
感知：读取用户输入、网页、数据库、API 返回、文件、传感器等信息。
规划：把大目标拆成小步骤，决定先做什么、后做什么，失败后怎么重试。
记忆：短期记忆当前对话，长期记忆用户偏好、历史任务、知识库。
工具：搜索、写代码、发邮件、查数据库、操作浏览器、调用 API。
执行：真正采取行动，而不只是输出一段文字。
循环：观察 → 思考 → 行动 → 看结果 → 再调整，直到完成目标。
和普通聊天机器人的区别
普通聊天机器人主要是：你问，它答。
Agent 更像是：你给目标，它自己想办法一步步完成。

比如：
聊天机器人：告诉你“如何订机票”。
Agent：查航班、比价、填信息、调用支付接口，最后把票订好。
常见类型
单 Agent：一个智能体独立完成任务。
多 Agent 系统：多个 Agent 分工协作，比如一个写代码、一个测试、一个审查。
强化学习 Agent：在环境中不断试错，学习最优策略。
软件 Agent：如监控 Agent、代理服务器、User-Agent 等，是更传统的“代理程序”含义。
Agent 是一个能自主规划并采取行动来完成目标的智能代理；在 AI 语境下，通常指以 LLM 为核心、能调用工具和多步执行的智能体。

在牢理@Mashiro_Neri跟柠檬@LecitronArts的嘲讽下，我终于是下载了opencode

然后我完成了第一个项目————迁移dsh计费插件，转化为vsc插件

这是使用dsv4.1f完成迁移的项目，人物是用官方立绘投给了豆包得到的，一共花费了1.9rmb
项目本身的问题很快就出现了

  • 一是项目在实时模式下冷启动的问题，同时前后端显示有一定延迟，不同步
  • 二是角色换图片后没办法换回去
  • 三是第一次点击大肥鱼没办法鸭子叫，让我十分愤怒

将这些bug描述后，很快就给我解决了（30min 愉快的刷起了抖音）
在我喜欢看AI干了什么，因为 Agent 能“行动”，所以风险比聊天机器人更大：
可能误操作（删除正确代码）、被提示注入攻击（中转站耍起）、泄露数据（直接发布密码到公开仓库）、乱花钱（这是对的大肥鱼，吃白饭耍起嘛）、调用错误工具（听不懂话的傻福模型）
因此通常需要权限控制、沙箱、审计日志、人类确认
当然无视风险继续安装的人也不少，丢掉大脑直接权限全开
这时候我对Agent的期待拉满了，什么都想AI干，但是这种日子总有苦头……
未完待续。

我饿了给我炒俩菜

而不是跟我这种原始人第一次用一样：

我需要番茄炒鸡蛋，使用的技术栈是大锅柴火灶，需要勾芡浓汤收汁，适当加入白糖提鲜

所以说AI是振幅器。
室友跟我开玩笑，说AI虽然很舒服但是一点都不强，我就开玩笑的回复到：你用得最多的估计是豆包拍照搜题
这也是为什么他们认为AI编程还处于一个拉跨阶段的原因之一
